## 질문
기온과 일사량이 높아질수록 대기 중 오존 농도는 정말 증가할까?

## 왜 이 주제인가 (팀이 씁니다)
팀이 이 주제를 고른 이유 한 문단. 
: 평소 대기 오염 문제가 우리의 일상생활과 건강에 미치는 영향에 관심이 있었으며, 특히 여름철에 오존 주의보가 자주 발령되는 현상에 주목하였다. 오존은 단순히 기온이 높아진다고 생성되는 것이 아니라, 햇빛에 의한 광 화학 반응을 통해 생성되는 물질이라는 점에서 기온과 일사량이 오존 농도에 미치는 영향을 구체적으로 알아보고자 하였다. 이에 기온과 일사량이 높아질수록 실제 대기 중 오존 농도도 증가하는지 공공 데이터를 활용해 분석하고, 화학적 반응 원리와 실제 환경 현상 사이의 관계를 데이터에 근거하여 탐구하고자 본 주제를 선정하였다.


## 데이터
1. 공공데이터포털 - 한국환경공단 에어코리아 대기오염정보
2. 공공데이터포털 - 기상청 지상(종관, ASOS) 시간자료 조회서비스

기간·행·열 수: 2025년 6월 1일~8월 31일, 시간별 자료 / 결합 후 최대 2,208행(결측 및 시간 불일치 자료 제외) / 약 6~8개 열
날짜 및 시간측정소,기온(℃),일사량,오존 농도(ppm),풍속(m/s) (추가 분석용)이 사용된다

회귀 · 군집 · 연관 중 하나. 왜 이 방법인지 한두 문장.
-회귀분석을 활용한다. 기온과 일사량을 독립변수, 오존 농도를 종속변수로 설정하여 두 기상 요인이 오존 농도 변화와 어떤 관계를 가지는지 정량적으로 분석할 수 있기 때문이다.

분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜): 
1. 데이터 수집: 에어코리아와 기상청에서 시간별 오존 농도 및 기상 관측 자료 수집
2. 변수 선택: 날짜, 시간, 기온, 일사량, 오존 농도, 풍속 선정
3. 전처리: 날짜와 시간을 기준으로 두 데이터 결합, 결측값 및 이상값 확인
4. 분할: 데이터를 학습용 80%, 평가용 20%로 분할
5. 기준선: 오존 농도의 평균값을 기준으로 예측 오차 비교
6. 후보 모델 비교: 단순선형회귀와 다중선형회귀 비교
7. 선택: 평가 데이터에서 예측 오차가 더 작은 모델 선정
8. 평가: 결정계수(R²), 평균절대오차(MAE)로 모델 성능 평가
9. 해석: 기온과 일사량이 오존 농도와 갖는 관계를 해석하고 화학적 원리와 연결
