# 3차시 기록 — (오늘 한 일 한 줄)

## 20706 최라임
- 오늘 결정한 것:기온과 일사량이 대기 중 오존 농도에 미치는 영향을 분석하고, 실제 관측 데이터와 화학적 원리를 연결하여 결과를 해석하기로 했다.
- AI에게 보낸 프롬프트(원문):내가 데이터 보고 다 분석하니깐 2025년 06월 19일이 33도로 젤 기온이 높았어 이 때의 오존 농도는 0.0276인데 실제로 오존 농도가 제일 높았던건 6월 5일 0.0407이야 7월달은 7월 24일이 기온이 가장 높았고 이 때의 오존 농도는 0.0231이고 하지만 7월 3일의 오존 농도가 0.0303으로 제일 높아 8월달은 24일이 가장 높고 이때의 오존 농도는 0.0247이며 하지만 8월 16일이 0.0321로 오존 농도가 제일 높아
  
- AI가 준 것 중 고치거나 버린 것과 그 이유:또한 AI가 제시한 예상과 달리 실제 분석에서는 최고 기온일과 최고 오존 농도일이 일치하지 않았으므로, 실제 관측값을 바탕으로 결과를 수정하였다.
  
- 느낀 점:AI는 탐구 주제 선정과 데이터 분석 방향을 설정하는 데 도움을 주었지만, AI가 제시한 정보가 항상 정확한 것은 아니라는 점을 느꼈다. 특히 실제 데이터를 직접 분석하고 AI의 예상과 비교하는 과정에서 자료를 비판적으로 검토하는 태도가 중요하다는 것을 깨달았다.

- AI 없이 내가 스스로 한 것:2025년 6~8월의 기온과 오존 농도 데이터를 직접 확인하고, 각 달의 최고 기온일과 최고 오존 농도일을 찾아 수치를 비교하였다. 또한 실제 분석 결과를 바탕으로 처음 세운 가설을 재검토하고 탐구 결과와 한계를 정리하였다.
